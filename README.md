# KnowHow 法律新媒体平台（对外说明）

> 文档属性：正式版（对外）  
> 适用场景：汇报、路演、评审、成果展示

## 一、项目定位

KnowHow 法律新媒体平台聚焦“法律内容传播 + 法律服务连接 + 运营分析支持”，以清晰、可信、可达为核心原则，面向公众法律认知提升与法律服务协同场景。

平台以“法律的专业性、表达的可理解性、服务的可获得性”为建设目标，持续优化内容质量与服务体验，提升法治信息触达效率。

---

## 二、建设目标

| 目标方向 | 目标说明 |
|---|---|
| 普法传播 | 通过多类型内容提升法律知识触达率与理解度 |
| 服务连接 | 打通用户诉求与专业服务响应链路 |
| 运营支撑 | 提供可视化看板支持运营监测与策略优化 |
| 体验提升 | 兼顾信息准确性与产品易用性 |

---

## 三、业务模块

| 模块名称 | 功能概述 |
|---|---|
| 首页与平台简介 | 政务门户式首页（借鉴法院官网风格）：顶部保留平台欢迎横幅（KnowHow 定位与关怀语）、热点头条焦点轮播（配真实要闻配图）、服务大厅快捷入口（按角色展示，律师工作台仅律师/管理员可见）、要闻/法规/推荐/公告/数据/讨论等信息专区，统一展示平台定位与服务价值 |
| 内容中心 | 法治头条聚合真实要闻、图片与原文链接；影视中心提供普法视频与法治栏目内容，封面采用"视频画面+文字说明"风格；民法典在线阅读支持编章目录导航、全文检索与一键复制 |
| 页面呈现 | 各板块顶部主模块采用首页式主题横幅（实拍主题图 + 遮罩 + 白色标题），配图按板块主题独立选取、互不重复；首页沿用政务门户风格 |
| 交流互动 | 法律论坛：知乎式紧凑帖子列表（标题+摘要+缩略图），点击进入详情页查看全文并在详情内回复评论，支持点赞（按账号去重、可取消）、浏览量统计、内联编辑、号主可删除自己的帖子、封面图异常兜底；交流中心：好友申请与审批（已处理的申请在通知中仅显示结果状态）、实时消息收发（多端自动同步）、2 分钟内撤回、消息删除、未读提醒（聊天/好友未读气泡按需显示、通知一键全部已读）；法律互动中心：法律咨询、案件发布、消息中心（消息多端实时同步，号主可删除自己发布的咨询/案件/消息） |
| 服务连接 | 支持法律咨询、服务匹配与状态跟踪 |
| AI 法律咨询 | 登录后智能法律引导，支持语音朗读、气泡式对话、历史记录按账号隔离与常用问题快捷提问 |
| 个性化体验 | 两套主题风格（深蓝 / 红白）、护眼模式、字号三档与设置中心，适配不同阅读场景 |
| 管理后台 | 提供内容、服务与运营数据的综合管理能力；律师入驻申请实时同步至后台，待审核数量自动更新，管理员在线即可通过/拒绝，无需刷新 |
| 运营看板 | 提供指标展示、趋势分析、结构分析与内容表现评估 |

## 五、运营看板说明

运营看板采用“概览 + 趋势 + 结构 + 表现”四层结构，服务于日常运营复盘和阶段性汇报。

### 1）结构组成

| 区域 | 说明 |
|---|---|
| 指标概览区 | 展示关键业务指标及变化趋势 |
| 趋势分析区 | 展示主指标与对比指标走势 |
| 渠道构成区 | 展示渠道占比结构与补充指标 |
| 内容表现区 | 展示重点内容的综合表现 |

### 2）交互说明

| 交互动作 | 响应结果 |
|---|---|
| 切换分析维度 | 看板数据同步刷新 |
| 切换观察周期 | 图表与指标按周期重绘 |
| 点击图表节点 | 弹出对应数值信息 |
| 点击结构项 | 展示对应占比结果 |
